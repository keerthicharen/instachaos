UI-GONE-BAD---Instachaos
InstaChaos: Instagram's UI cloned, then sabotaged. Buttons mislead, menus shift, popups resist closing, gestures reverse, timers vanish mid-click. Every feature—posting, stories, DMs, notifications—works, just maddeningly hidden behind confusing, illogical flows designed to frustrate, never break.

InstaChaos 🌀
A fully functional, deliberately terrible Instagram clone — built to explore bad UX on purpose.

InstaChaos is a satirical UI/UX project inspired by sites like User Inyerface. It clones every major Instagram feature — feed, posting, stories, DMs, notifications, search, explore, and profile management — but reimagines the interface to be as confusing, misleading, and frustrating as possible, without ever actually breaking.

Nothing crashes. Nothing 404s. No data is lost. The frustration is 100% intentional, presentation-layer chaos.

Why?
This project exists as:

A teaching tool for spotting and avoiding real-world dark patterns and bad UX
A design exercise in "expected vs. actual behavior" deltas
A genuinely fun (and mildly infuriating) portfolio piece
Features (all "working," none behaving)
Instagram Feature	InstaChaos Twist
🏠 Feed	Re-sorts mid-scroll, likes open a rotating reaction wheel
📸 Posting	Composer hidden behind a long-press; Share button is a 2px sliver
🎬 Stories	Tap directions reversed, exit button fades to near-invisible
💬 DMs	Send button relocates on every message, read receipts inverted
🔔 Notifications	Badge always shows "1", Clear All only clears old items
🔍 Search & Explore	Results filter after 3s of silence, grid re-flows every 8s
👤 Profile	Followers/Following labels swap on tap
